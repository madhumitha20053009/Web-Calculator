# Web-Calculator

The Web Calculator is a simple and user-friendly web application developed using HTML, CSS, and JavaScript. 
It performs basic arithmetic operations such as addition, subtraction, multiplication, and division. 
The project provides an interactive interface with buttons for numbers and operators. 
JavaScript is used to handle calculations and display the results instantly. 
This project helps to understand the fundamentals of web development, including DOM manipulation, event handling, and responsive UI design.

Technologies Used:

HTML – Structure of the calculator
CSS – Styling and layout
JavaScript – Calculation logic and functionality

Project Objective:

To develop an efficient and interactive online calculator that performs mathematical operations accurately and improves basic web development skills.
